# 編輯器改版 批 2：打字與插入（v3.11.0）

日期：2026-10-04
來源：2026-10 編輯器逐項審查 E3、E4、E5、E6、E7（定案見 `2026-10-04-editor-overhaul-index.md`）
前提：批 1（`2026-10-04-editor-batch1-design.md`，v3.10.0）已發布——外觀 token、深色、Lucide 圖示、`showError`／`showNotice` 都已存在，本批直接使用。

函式以名稱為錨點（`lib/editor/client.js` 行號變動很快，實作時用 `grep -a -n` 重新定位；該檔含 NUL 位元組，一般 `grep` 會當成二進位）。

## 1. 目標

讓編輯器的打字與插入手感接近 Notion：Enter 切段、Backspace 合併、段首 Markdown 符號自動轉換、「/」選單、點空白處就能打字；＋ 與「/」共用同一份選單；連結不再用 `window.prompt`；鬆散清單可以直接編輯；表格選單可插入欄列、尾端可加列加欄。

成功標準：第 9 節的測試全綠；`npm run test:browser` 的編輯器點擊檢查在 Chromium 與 WebKit 通過；使用者回報的「空白 md 連插入新行都做不到」以點擊測試重現並轉綠。

## 2. 共同前提：空段落在 Markdown 裡不存在

Notion 可以保留空的區塊，Markdown 不行——空段落沒有任何原始碼行。本批所有「產生空段落」的動作都遵守同一個模型：

- **暫時空段落**：只存在於畫面上的可編輯區塊，`data-ed-transient="1"`，不對應任何原始碼行，不產生 undo op。
- 使用者在裡面打了字並離開（blur、Enter、切到別的區塊）→ 以一次 `commitRangeEdit` 插入對應位置，成為一般段落，算一個 undo op。
- 離開時仍是空的 → 直接從畫面移除，原始碼不變，不產生 undo op。
- 暫時空段落一次最多一個；產生新的會先把舊的（空的）收掉。
- 插入位置用「在某個實體區塊之後／之前」表示（區塊 id），文件為空時表示「文件開頭」。

以下 E3、E4 的動作都建立在這個模型上，實作計畫第一個任務就是它（含測試），之後的任務才接上去。

## 3. 打字行為（E3）

範圍：段落與標題（`handleBurstKeydown`）。清單項目已有自己的 Enter／Tab 行為（`handleLiKeydown`、`splitListItemAtCaret`），本批只補 Backspace 合併與 Markdown 轉換，不改既有清單 Enter。表格儲存格的 Enter 維持插 `<br>`。

### 3.1 Enter 切段

- 段落中按 Enter：游標前的內容留在原段，游標後的內容成為新段落，游標移到新段落開頭。一次 `commitRangeEdit`（原段的行換成兩段），一個 undo op。
- 游標在段尾：原段不變，下方產生暫時空段落（第 2 節）。
- 游標在段首且段落非空：上方產生暫時空段落，游標留在原段（Notion 行為）。
- 標題中按 Enter：游標前留在標題；游標後成為一般段落（不是標題）。在標題尾端按 Enter → 下方暫時空段落。
- 行內格式跨切點時（例如粗體中間切開）：兩半各自序列化，用 `inline-md.js` 既有的序列化確保兩邊各自成對閉合。
- Shift+Enter 段內換行不變。原本「Enter 送出並離開」的行為移除；送出改由 blur／Esc 以外的既有路徑處理（Esc 仍是還原整段）。

### 3.2 段首 Backspace

- 游標在段首（且沒有選取）：
  - 本段是標題或清單項目 → 先轉成一般段落（`convert-md.js` 的「文字」目標），不合併。一個 undo op。
  - 本段是一般段落、上一個區塊是段落或標題 → 本段文字接到上一段尾端，游標停在接縫。一個 undo op（兩段的行換成一段）。
  - 上一個區塊是表格、程式碼、圖表、分隔線、圖片 → 不合併；本段空的話刪掉本段，游標移到上一個區塊之後的位置；非空則選取上一個區塊（區塊選取狀態），再按一次 Backspace 才刪它。
  - 本段是暫時空段落 → 移除它，游標移到上一段尾端。
- Delete 在段尾：對稱行為（把下一段併上來）。

### 3.3 段首 Markdown 符號自動轉換

在段落開頭輸入以下序列後（觸發字元是最後那個空白或第三個反引號／減號），立即轉換：

| 輸入 | 轉成 |
|---|---|
| `# ` `## ` `### ` `#### ` `##### ` `###### ` | 標題 1–6 |
| `- ` 或 `* ` | 項目符號清單 |
| `1. `（任意數字） | 編號清單（起始號沿用輸入的數字） |
| `[] ` 或 `[ ] ` | 待辦清單 |
| `> ` | 引用 |
| ```` ``` ```` | 程式碼區塊（反引號後若有語言名稱，在按 Enter 時套用） |
| `---` | 分隔線，並在下方產生暫時空段落 |

- 只在段首、且該序列前沒有其他文字時觸發；段落中間打不會轉。
- 轉換後立刻按 Ctrl/Cmd+Z → 還原成使用者打的字面（不是還原到轉換前的再前一步）。實作：轉換本身是一個 undo op，其 undo 結果是「段落內容＝打出來的字面」。
- 在清單項目裡打這些序列不轉換（避免清單中寫 `- ` 被吃掉）。

### 3.4 「/」選單

- 觸發：在段落或暫時空段落中，游標前是段首或空白時打「/」。選單開在游標下方（空間不夠時翻到上方）。
- 版面（E3 定案 M1）：寬 280px、項目 32px、16px 線條圖示＋名稱＋右側 Markdown 符號（淡色等寬字）、分組標題、底部一行按鍵提示「↑↓ 選擇　Enter 插入　Esc 關閉」；外觀用批 1 的選單 token。
- 項目（15 項，四組）：

| 組 | 項目 | 右側提示 |
|---|---|---|
| 基本 | 文字、標題 1、標題 2、標題 3 | —、`#`、`##`、`###` |
| 清單 | 項目符號列表、編號列表、待辦清單 | `-`、`1.`、`[]` |
| 區塊 | 引用、程式碼、分隔線、表格、圖片 | `>`、```` ``` ````、`---`、—、— |
| 圖表 | Mermaid 圖、Graphviz 圖、WaveDrom 波形、數學公式 | —、—、—、`$$` |

- 篩選：「/」之後打的字即時篩選，比對名稱與關鍵字（中英文都收：例如表格＝「表 table」、標題 2＝「h2 heading」、程式碼＝「code 程式」、圖片＝「image img 圖」、Mermaid＝「mermaid 流程 圖」）。沒有符合項目時顯示「沒有符合的區塊」，再打一個空白或 Esc 關閉，保留字面。
- 鍵盤：↑↓ 移動（循環）、Enter 或 Tab 插入、Esc 關閉並保留已打的字。滑鼠點選同 Enter。
- 插入規則：
  - 若「/」所在段落除了「/篩選字」外是空的 → 該段直接換成目標區塊。
  - 否則 → 刪掉「/篩選字」，目標區塊插在本段下方。
  - 文字／標題／清單／引用：用 `convert-md.js` 的轉換。
  - 程式碼：空的 ```` ``` ```` 圍欄；Mermaid／Graphviz／WaveDrom：對應語言的圍欄＋最小可渲染範例（例如 `graph TD\n  A --> B`、`digraph { a -> b }`、一條 clock 訊號）；數學公式：`$$\n\n$$`。
  - 表格：沿用 `buildInsertMenu` 現有的 3 欄 × 2 列骨架。
  - 圖片：開檔案選擇器，走既有 `insertImages`（`/api/asset` 上傳）。
  - 分隔線：`---`，下方產生暫時空段落。
- 每次插入是一個 undo op。

### 3.5 空白處與空白文件

- 空白文件（0 個區塊）開啟時顯示一個暫時空段落並聚焦。
- 點最後一個區塊下方的空白處（`.content` 底部到視窗底之間）→ 在文件尾端產生暫時空段落並聚焦。若最後一個區塊本身已是空的暫時段落，只聚焦它。
- 聚焦的空段落（暫時或實體空）顯示淡灰提示文字「輸入文字，或按「/」選擇區塊」（CSS `::before` + `data-placeholder`，不進 DOM 文字，不會被序列化）。

### 3.6 與既有功能的關係

- 區塊選取、拖曳、⠿ 選單、↑↓ 跨區塊移動（`walkToAdjacentBlockByArrow`）行為不變；↑↓ 要能走進與走出暫時空段落。
- 貼上（`handleArmedPaste`）在暫時空段落中：等同在該位置插入，貼上的內容取代這個暫時段落。

## 4. ＋ 插入（E4 剩餘）

- 點 ＋ → 在該區塊下方產生暫時空段落，並在裡面打開「/」選單（等同在新段落打了「/」，但不寫入「/」字元）。使用者定案：「＋ 的行為跟 / 應該一樣的表單，不需要額外設計一種顯示」。
- Alt＋點 ＋ → 改插在上方。
- 原本的橫向 5 種膠囊（`buildInsertMenu`／`INSERT_KIND_LABELS`）移除；它的表格骨架與程式碼骨架邏輯搬給「/」選單共用。
- 工具列的「在上方插入／在下方插入」（⬆⬇）改成同一行為：產生暫時空段落並開「/」選單。

## 5. 連結（E5 剩餘）

- **網址欄**：點選字工具列的連結鈕或按 Ctrl/Cmd+K → 選字工具列原地變成網址欄（左側連結圖示、輸入框 placeholder「貼上或輸入網址」、右側「套用」鈕）。Enter 套用、Esc 取消並回到選字工具列；輸入框清空後 Enter ＝移除連結。選取範圍已在連結內時，欄位預填原網址。取代 `applyLinkToggleBody` 裡的 `window.prompt`。
- **貼網址成連結**：有非空選取時貼上的純文字是單一網址（`^https?://\S+$`）→ 把選取的文字變成連結，不插入網址字面。沒有選取時照常貼上。
- **連結小卡**：游標（collapsed）停在連結內 300ms → 連結下方出現小卡：網址（過長以 … 截斷）、開啟（新分頁）、編輯（回到網址欄）、移除連結。游標離開連結或按 Esc 收起。滑鼠 hover 連結不觸發（避免閱讀時干擾）。
- 每次套用／移除是一個 undo op（沿用現有 burst 規則）。

## 6. 鬆散清單可直接編輯（E6 剩餘）

- 現況：`lib/editor/list-md.js` 對包著 `<p>` 的清單項目主動 `unsupported.push('P')`（「loose list item — see header decision」），整項降級成原始碼框。mac-tx-core 240 個清單項目中有 23 個降級，大多是這個原因，少數因為含 `<a id>` 錨點。
- 設計：
  - 單一 `<p>` 的鬆散項目當成一般項目編輯；序列化時保留該清單原本的鬆散性（項目之間的空行）。鬆散性以「整段清單」為單位記錄，從原始碼判定（項目間是否有空行），不從 DOM 猜。
  - 新增項目（Enter 切項）時沿用該清單的鬆散性。
  - 項目內有多個段落（兩個以上 `<p>`）仍降級，不在本批。
  - 含原始 HTML（例如 `<a id="…">`）的項目仍降級，不在本批。
- 必須通過 `byte-stability.test.js` 與 `roundtrip.test.js` 的精神：不編輯就存檔，原檔位元組不變；編輯一項，只有那一項的行改變。
- 實作計畫要先列出 mac-tx-core 23 個降級項目各自的原因，確認本批之後剩下的都屬於「多段落」或「原始 HTML」。

## 7. 表格（E7）

### 7.1 直式欄／列選單

取代 `showColumnMenu`／`showRowMenu` 的橫向膠囊。外觀同 ⠿ 選單（批 1 token、16px 圖示＋文字、30px 項目）。

- 欄選單：左側插入欄、右側插入欄、對齊（同一行三顆：靠左／置中／靠右，目前對齊方式為 pressed）、分隔線、刪除欄（紅字 `ed-err`）。
- 列選單：上方插入列、下方插入列、分隔線、刪除列（紅字）。表頭列沒有「上方插入列」與「刪除列」（維持現有表頭保護）。
- 位置：開在把手旁、表格內側（欄選單在欄把手下方；列選單在列把手右側），不超出視窗；不再蓋到側欄。
- 插入沿用格線泡泡已有的插入邏輯（`onColInsertBubbleClick`／`onRowInsertBubbleClick` 背後的函式）；對齊改為直接設定（`runCycleAlign` 的循環行為保留給鍵盤，選單用直接設定）。
- 鍵盤：選單開著時 ↑↓ 移動、Enter 執行、Esc 關閉（沿用既有 Esc 優先序）。

### 7.2 尾端加列加欄

- 指標在表格上時，表格下方出現 22px 高、與表格同寬的淡灰長條（`ed-hover` 底、中間 ＋ 圖示），右側出現同樣的直條（與表格同高）；指標離開表格與長條 300ms 後隱藏。
- 點下方長條 → 在最後加一列並把游標放進新列第一格；點右側直條 → 在最右加一欄並把游標放進表頭新格。
- 表格寬到超出內容欄（橫向捲動）時，右側直條貼著可視範圍右緣。
- 格線上的 ＋ 泡泡（`updateTableInsertBubbles`）保留，用來插在中間。

### 7.3 Tab

- 在最後一格按 Tab → 新增一列並把游標放進新列第一格（取代目前 `leaveTableByTab` 離開表格的行為）。
- Shift+Tab 在第一格維持離開表格到上一個區塊。
- 要離開表格往下：↓ 方向鍵在最後一列（既有行為）或點表格外。

## 9. 測試

### 9.1 單元（`npm test`）

- 暫時空段落模型：產生、打字後提交成一個 op、空著離開不產生 op、同時最多一個。
- Enter 切段：段中、段尾、段首、標題、跨粗體切點；每種一個 undo op，undo 後原文位元組相同。
- Backspace 合併：段落＋段落、標題轉段落、清單項轉段落、上一個是表格時的選取行為、暫時段落移除。
- Markdown 自動轉換：表內每個序列各一；段中不觸發；清單內不觸發；轉換後 undo 得到字面。
- 「/」選單：15 項全部插入後的原始碼（逐項斷言產生的 Markdown 文字）；中英文篩選；無符合項目。
- 鬆散清單：mac-tx-core 的鬆散清單不編輯存檔位元組不變；編輯一項只改那幾行；新增項目保留空行。
- 表格：每個選單動作產生的 Markdown；尾端加列加欄；最後一格 Tab 新增列。
- 連結：網址欄套用／移除／預填；貼網址成連結；非網址照常貼上。

### 9.2 編輯器點擊檢查（`npm run test:browser`，Chromium＋WebKit）

延伸批 1 的 `test/editor-click.test.js`，每項以真實按鍵與點擊、DOM 幾何斷言：

1. 開空白 md：有一個聚焦的空段落與提示文字；打字後 Ctrl+S，檔案內容等於打的字。
2. 點短文件最後一段下方空白處 → 出現聚焦的空段落；打字、存檔，字出現在檔尾。
3. 段中 Enter → 兩段；段首 Backspace → 合併回一段，檔案位元組與原本相同。
4. 段首打 `## ` → 變成 H2；立刻 Ctrl+Z → 回到字面 `## `。
5. 打「/」→ 選單出現在游標下方、15 項；打「表」→ 只剩表格；Enter → 插入 3×2 表格。
6. 點 ＋ → 下方出現空段落且選單打開；Alt＋點 ＋ → 插在上方。
7. 選字後 Ctrl+K → 網址欄出現在原選字工具列位置；輸入網址 Enter → 連結建立；游標停在連結內 → 小卡出現。
8. 鬆散清單項目點進去可直接打字（不是原始碼框）。
9. 表格欄把手 → 直式選單在表格內側且未超出視窗；「右側插入欄」後欄數 +1；點下方長條加一列；最後一格 Tab 加一列。

每個情境要確認出現在輸出裡，不能因為前一個情境丟例外而沒跑到（CLAUDE.md：長套件裡第一個例外會讓後面全部靜默不執行）。

## 11. 風險

- **Enter／Backspace 改的是最常用的按鍵**：任何錯誤都會直接改壞使用者的檔案。對策：每種情況都有「undo 後位元組相同」的單元測試；點擊檢查在兩個引擎跑。
- **暫時空段落與既有區塊模型的接縫**：區塊選取、拖曳、↑↓ 導覽、`/api/render` 局部重建都假設每個區塊有原始碼行。對策：暫時段落一律標 `data-ed-transient`，計畫裡逐一列出會遍歷 `.ed-block` 的函式並決定各自要不要跳過它。
- **WebKit 的 contenteditable 差異**：Enter 與 Backspace 在 Safari 的預設行為不同。對策：全部 `preventDefault` 後自行處理，不依賴瀏覽器預設。
- **鬆散性判定**：從原始碼判定，不從 DOM 猜；判斷錯會讓整段清單的空行全部改變。對策：位元組穩定測試。
