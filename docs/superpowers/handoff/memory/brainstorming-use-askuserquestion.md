Brainstorming 時的選擇題／批准點一律用 AskUserQuestion tool 問，不要在回覆文字裡列 A/B 讓使用者打字回。推薦選項放第一個並標 (Recommended)。

**Why:** 使用者 2026-09-23 糾正：「你沒用 askuser，這是 brainstorming」。
**How to apply:** 每個 brainstorming 問題（含 design 批准）都走 AskUserQuestion；文字只放背景／量測結果。
