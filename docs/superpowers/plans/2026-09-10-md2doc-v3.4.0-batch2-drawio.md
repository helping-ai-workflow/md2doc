# md2doc v3.4.0 批次 2 — drawio 內嵌 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `![](x.drawio)` 與 `![](x.xml)` 在建置時被烤成內嵌 SVG，產出的 HTML 完全離線可用、不夾帶 4 MB 的 drawio viewer，多頁可切、可進 lightbox。

**Architecture:** 完全照 graphviz 那條既有的路：`renderer.image` 產出帶 base64 來源的佔位 `<div>`，非同步 post-pass `bakeDrawio()` 逐 part 把它換成內嵌 SVG。引擎（diagrams.net 的 `viewer-static.min.js`）跑在 Node 側的 headless Chromium 裡，不進輸出的 HTML。多頁一次全烤，切頁只切 `hidden`，不需要引擎。

**Tech Stack:** Node.js、puppeteer 24（既有依賴，PDF 匯出在用）、diagrams.net `viewer-static.min.js`（Apache-2.0，隨套件出貨）。

**Spec:** `docs/superpowers/specs/2026-09-10-md2doc-v3.4.0-design.md` §4

## Global Constraints

- **絕不 `git add` `docs/superpowers/` 或 `.superpowers/`。**
- **不引進 build step、不引進新的 runtime npm 依賴。** viewer 是隨套件出貨的靜態資產，不是 npm 依賴。
- **產出的 HTML 不得含任何 `viewer.diagrams.net` 的 URL**，也不得含 `viewer-static`。這是本批次最重要的驗收條件——md2doc 的立身之本是自帶一切的單檔 HTML。
- **`lib/editor/client.js` 不得出現那九個裸子字串**（見批次 1 的 Global Constraints；本批次若要動 client.js 同樣適用）。
- **不准對任何既有測試 `skip` / `xfail`，不准放寬任何斷言。**
- **新增的測試檔必須加進 `package.json` 的 `test` script。**
- **實作者不得執行 `npm test` 或 `node test/editor-client-runtime.test.js` 或 `node test/editor-journey.test.js`**（各 20-25 分鐘）。需要跑就回報 `NEEDS_RUN`。
- **跑測試時絕不 pipe**——exit code 會變成 pipeline 尾端的。導向檔案再讀檔。
- **一律用引文錨點定位，不要用行號。**
- **CSS 鐵則**：`.lightbox-canvas` 以 px 調整尺寸，**不得**改用 `transform: scale()`（scroll extent 不會跟著變，放大後的邊緣點不到，`test/lightbox.test.js` 有守）；`.lightbox-stage` 必須維持 `position: relative`。
- **clean-room**：可以讀 `CN5DD2_common/apps/vscode-office/resource/markdown/drawioPreview.js` **當行為規格**，不得複製其程式碼。第三方 OSS（`viewer-static.min.js` 本身）不受此限。

```js
'use strict';

// drawio (.drawio / .xml) 來源的判別與頁面解析。
//
// 這一支刻意不碰 marked、不碰瀏覽器 —— 判別與頁名是純字串處理，可以用純函式
// 測；真的需要 headless Chromium 的只有 bakeDrawioSvg()（見同檔下方）。
//
// 為什麼不用 XML parser：md2doc 不引進新的 runtime 依賴，而這裡要回答的問題
// （根元素是什麼、有哪些 <diagram name>）用受控的 regex 就夠。輸入是本機檔案
// 而不是網路內容，且判別失敗的後果是「當成普通圖片、原樣留著」——不是安全邊界。

// 開頭的 XML 宣告、DOCTYPE、註解、空白都要跳過，才看得到真正的根元素。
const LEADING_NOISE = /^(?:\s|<\?[\s\S]*?\?>|<!--[\s\S]*?-->|<!DOCTYPE[^>]*>)*/;

function isDrawioXml(text) {
  const s = String(text || '');
  const rest = s.slice(s.match(LEADING_NOISE)[0].length);
  return /^<(?:mxfile|mxGraphModel)[\s>]/.test(rest);
}

function pageNamesOf(text) {
  const s = String(text || '');
  if (!/^\s*(?:<\?[\s\S]*?\?>|<!--[\s\S]*?-->|\s)*<mxfile[\s>]/.test(s)) {
    // <mxGraphModel> 直接當一頁，沒有名字。
    return [''];
  }
  const names = [];
  const re = /<diagram\b([^>]*)>/g;
  let m;
  while ((m = re.exec(s)) !== null) {
    const nameAttr = /\bname\s*=\s*"([^"]*)"/.exec(m[1]);
    names.push(nameAttr ? nameAttr[1] : '');
  }
  return names.length ? names : [''];
}

function resolvePageIndex(names, fragment) {
  const frag = String(fragment == null ? '' : fragment);
  if (!frag) return 0;
  const byName = names.indexOf(frag);
  if (byName >= 0) return byName;
  if (/^\d+$/.test(frag)) {
    const n = Number(frag);
    if (n >= 1 && n <= names.length) return n - 1;
  }
  return 0;
}

module.exports = { isDrawioXml, pageNamesOf, resolvePageIndex };
```

- [ ] **Step 3: 實作 `bakeDrawioSvg()`**

放在 `lib/drawio.js`：

```js
const fs = require('fs');
const path = require('path');

const VIEWER_PATH = path.join(__dirname, '..', 'vendor', 'drawio', 'viewer-static.min.js');

// 每一頁烤成一份 SVG。
//
// 為什麼是 headless Chromium 而不是 Node 裡的某個函式庫：drawio 的版面
// 計算（自動換行、文字度量、stencil 形狀）依賴真正的瀏覽器排版引擎，
// 沒有等價的 Node 實作。md2doc 已經有 puppeteer（PDF 匯出在用），所以這
// 不是新依賴。
//
// 六個遠端路徑預設值必須在 viewer 載入之前就改寫掉。viewer 自己的第一行
// 是 `window.PROXY_URL = window.PROXY_URL || "https://viewer.diagrams.net/proxy"`
// 這種形式 —— `||` 代表先設好的值會勝出，所以 addScriptTag 之前先 evaluate。
async function bakeDrawioSvg(xmlText, opts) {
  const o = opts || {};
  const names = pageNamesOf(xmlText);
  let browser = o.browser;
  let ownBrowser = false;
  if (!browser) {
    const puppeteer = require('puppeteer');
    browser = await puppeteer.launch({
      headless: 'new',
      args: ['--no-sandbox', '--disable-setuid-sandbox',
             '--disable-crash-reporter', '--disable-dev-shm-usage'],
    });
    ownBrowser = true;
  }
  const page = await browser.newPage();
  try {
    await page.setContent('<!doctype html><html><body></body></html>');
    await page.evaluate(() => {
      // 全部指向 about:blank 之下的相對路徑：viewer 取不到就用內建的
      // 基本形狀，而不是去打網路。md2doc 的輸出必須離線可用。
      window.PROXY_URL = '';
      window.STYLE_PATH = '';
      window.SHAPES_PATH = '';
      window.STENCIL_PATH = '';
      window.DRAW_MATH_URL = '';
      window.GRAPH_IMAGE_PATH = '';
      window.mxImageBasePath = '';
      window.mxBasePath = '';
      window.mxLoadStylesheets = false;
      window.mxLoadResources = false;
    });
    await page.addScriptTag({ path: VIEWER_PATH });

    const out = [];
    for (let i = 0; i < names.length; i++) {
      const svg = await page.evaluate((xml, pageIndex) => {
        const el = document.createElement('div');
        el.className = 'mxgraph';
        // width 不設會讓 GraphViewer 把圖縮到容器寬度。
        el.setAttribute('data-mxgraph', JSON.stringify({
          xml: xml, page: pageIndex, highlight: '#0000ff',
          toolbar: null, resize: true, nav: false,
        }));
        document.body.appendChild(el);
        window.GraphViewer.createViewerForElement(el);
        const svgEl = el.querySelector('svg');
        const html = svgEl ? svgEl.outerHTML : null;
        el.remove();
        return html;
      }, xmlText, i);

      if (!svg) {
        throw new Error('drawio viewer produced no SVG for page ' + (i + 1) +
          ' (' + (names[i] || 'unnamed') + ')');
      }
      out.push(svg);
    }
    return out;
  } finally {
    await page.close();
    if (ownBrowser) await browser.close();
  }
}
```

```js
  // v3.4.0 §4。回傳佔位元素，或 null 代表「這不是 drawio，照原路走」。
  function drawioPlaceholderFor(href) {
    if (!href || isExternalRef(href)) return null;
    const { filePart, fragment } = splitAssetRef(href);
    if (!filePart) return null;
    const ext = path.extname(filePart).toLowerCase();
    if (ext !== '.drawio' && ext !== '.xml') return null;

    const abs = resolveAssetPath(filePart);
    if (!abs) return null;   // 找不到檔案：交給既有的圖片路徑去 warn

    let xml;
    try { xml = fs.readFileSync(abs, 'utf8'); }
    catch (e) { return null; }

    if (!drawio.isDrawioXml(xml)) {
      // 副檔名對但內容不是 —— 對 .drawio 要說一聲，對 .xml 不必（.xml 本來
      // 就多半不是圖，靜靜走原路才是對的）。
      if (ext === '.drawio') {
        warnOnce(href, `[WARN] .drawio file is not mxfile/mxGraphModel, left as-is: ${href}`);
      }
      return null;
    }

    usesDrawio = true;
    const names = drawio.pageNamesOf(xml);
    const pageIndex = drawio.resolvePageIndex(names, fragment);
    const b64 = Buffer.from(xml, 'utf8').toString('base64');
    return `\n<div class="drawio" data-drawio-src="${b64}" data-drawio-page="${pageIndex}"></div>\n`;
  }
```

- [ ] **Step 4: 寫 `bakeDrawio()` 並掛進 post-pass**

與 `bakeGraphviz` 並列：

```js
async function bakeDrawio(htmlStr, browserRef) {
  if (!/data-drawio-src=/.test(htmlStr)) return htmlStr;
  const drawio = require('./drawio.js');

  // replace() 的回呼不能是 async，所以先蒐集再依序處理。
  const jobs = [];
  htmlStr.replace(
    /<div class="drawio" data-drawio-src="([^"]*)" data-drawio-page="(\d+)"><\/div>/g,
    (m, b64, pageIdx) => { jobs.push({ m, b64, pageIdx: Number(pageIdx) }); return m; });

  for (const job of jobs) {
    const xml = Buffer.from(job.b64, 'base64').toString('utf8');
    const names = drawio.pageNamesOf(xml);
    let svgs;
    try {
      // 一份文件共用一顆 browser：browserRef.get() 第一次才真的開。
      svgs = await drawio.bakeDrawioSvg(xml, { browser: await browserRef.get() });
    } catch (e) {
      console.error('[WARN] drawio render failed:', e.message);
      // 靜默的空白最貴（v3.3.0 反覆學到的）：留一個看得見的佔位。
      const msg = escapeHtml('drawio 圖無法渲染：' + e.message);
      htmlStr = htmlStr.replace(job.m,
        `<div class="drawio drawio-failed"><p>${msg}</p></div>`);
      continue;
    }
    const inner = svgs.map((svg, i) =>
      `<div class="drawio-page"${i === job.pageIdx ? '' : ' hidden'}>${svg}</div>`).join('');
    // 頁名可以含任何字元（逗號、引號都合法），所以不用分隔字元 —— 直接把陣列
    // 編成 base64 的 JSON，讀的那一端 JSON.parse 回來。用分隔字元的版本在
    // 「兩個頁名黏在一起」與「頁名裡剛好有那個字元」兩種輸入上都會壞掉，
    // 而且那個字元寫在文件裡是隱形的。
    const attr = Buffer.from(JSON.stringify(names), 'utf8').toString('base64');
    htmlStr = htmlStr.replace(job.m,
      `<div class="drawio" data-drawio-pages="${attr}">${inner}</div>`);
  }
  return htmlStr;
}
```
