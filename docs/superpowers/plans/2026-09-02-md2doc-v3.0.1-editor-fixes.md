# md2doc v3.0.1 編輯器點狀修正 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修掉 `md2doc --edit` 的三個使用者回報缺陷（清單 Tab 卡死、⠿ 選單圖示未對齊、表格列 grip 不在邊框上），並讓表格重新序列化時保留原始欄寬，使「改一格不再髒整張表」。

**Architecture:** 全部是點狀修改，不動 render 管線、不動 `lines[]` 寫入模型。四項互相獨立，任何一項失敗都不擋其他三項。表格欄寬保留是唯一會改變輸出位元組的項目，因此走完整 TDD 並加上 mutation-kill 等級的測試。

**Tech Stack:** Node.js ≥ 18、`marked` 14.x、Puppeteer（既有相依，用於 DOM 執行期測試）、`node:assert`。無新增相依。

**Spec:** `docs/superpowers/specs/2026-09-02-md2doc-editor-overhaul-design.md`

## Global Constraints

- **未編輯的內容必須 byte-identical。** `lib/editor/lineops.js` 的 `replaceLines()` 只重寫被編輯 block 的那幾行；`test/byte-stability.test.js` 與 `test/roundtrip.test.js` 守這條。本計畫任何一步都不得讓這兩個測試變紅。
- **`--ed-gutter-*` 與 `--ed-te-grip-row-w` 系列 CSS token 只寫一次、其他數值由它們衍生。** 不得新增第二處字面量。
- **⠿（`.ed-handle`）與 ＋（`.ed-insert`）不得掛上各自的 `addEventListener`。** `openRawEditor()` 的 `restore()` 會從字串重新解析 block 的 `innerHTML`，直接掛在節點上的 listener 會靜默消失。既有的委派式 listener 模式必須維持。
- **`lib/editor/table-md.js` 受限於節點測試的 stub**：只能使用 `childNodes` / `nodeType` / `nodeName` / `textContent` / `getAttribute`，**不得**使用 `querySelector` / `querySelectorAll`。
- **測試檔一律 RED-first。** 新增的測試檔必須加進 `package.json` 的 `test` script。
- **完整測試指令**：`npm test`（序列執行 31 個測試檔）。單檔執行：`node test/<name>.test.js`。
- **不得使用 `--no-verify`、不得 skip、不得 xfail。** 既有測試若因本次修改變紅，必須找出根因並遷移該測試，不得靜音。
- **grep 注意**：`lib/editor/client.js` 目前含有兩個控制位元組，`grep` 會判定為 binary 並**靜默截斷**結果。Task 1 修掉它之前，所有針對該檔的搜尋都必須加 `-a`（例如 `grep -an`）。

## 與 spec 的兩處偏離（實作前先確認）

1. **Task 2 不是 spec 寫的「刪掉一行」。** Spec §5 修正 3 說直接刪除 `if (self.listStart) return false;`。實作前重新推導發現那會放行一個新的壞情況：兩個以空行分隔的相鄰清單（`- a` / `- b` / 空行 / `1. c`），對 `1. c` 按 Tab 時前一個 block 仍是清單項，於是會被允許縮排；縮排後 `listRunOf()` 的向上走訪把兩張清單併成同一個提交跨距，重新序列化會吃掉中間那個空行——正是 Global Constraint 第一條禁止的「使用者沒碰的行被改寫」。本計畫改用更窄的守衛：**前一個 block 不是清單項，或兩者之間隔著空行時才拒絕**。使用者回報的 `1. XXX` / `- OOO` 兩行相鄰，不受影響。

2. **Task 1 是 spec 沒有的新增項目。** `lib/editor/client.js:6429-6430` 的 `tableIdentityOf()` 用兩個**字面控制位元組**（U+0001、U+0000）當分隔符。功能正確，但它讓 `grep` 把這個 9643 行的檔案判定為 binary 並靜默截斷輸出——本計畫的調查過程就被它誤導過一次。改成 `'\x01'` / `'\x00'` 轉義序列，執行期值完全相同，檔案變回純文字。零行為改變，但每個之後要 grep 這個檔的人都受益。

`lib/editor/client.js` 中，把 `indentListItem()` 開頭這幾行：


改成：

```js
    const all = allBlockEls();
    const i = all.indexOf(blockEl);
    if (i < 0) return false;
    const prev = liAttrs(all[i - 1]);
    // Rule (d), narrowed (v3.0.1). The old rule was `if (self.listStart)
    // return false` — the first item of a LIST has nothing above it to nest
    // under. That over-refused: a bullet outdented to indent 0 directly
    // BELOW an ordered item is a listStart (a ul following an ol) whose
    // previous block is a perfectly good parent, and the user could never
    // indent it back. The half that still has to be refused is the one the
    // old rule was really aimed at: two list tokens the user kept apart with
    // a BLANK LINE. Indenting the second one makes listRunOf() span both,
    // and re-serializing that span swallows the blank line — a rewrite of
    // lines nobody touched, which is the one thing this editor must never do.
    // Contiguity is a fact about the FILE, so it is read off `blocks`, not
    // guessed from the DOM.
    if (self.listStart) {
      if (!prev) return false;
      const prevRec = blockRecOf(all[i - 1]);
      const selfRec = blockRecOf(blockEl);
      if (!prevRec || !selfRec) return false;
      if (prevRec.endLine + 1 !== selfRec.startLine) return false;
    }
```

- [ ] **Step 1: 建立失敗測試檔**

Create `test/table-width.test.js`：

```js
'use strict';
// v3.0.1: serializeTable() must reuse the ORIGINAL column widths.
//
// Why this file exists: the emitter's minimal form ('| a | b |', '|---|')
// rewrites every line of a hand-aligned table the moment one cell changes.
// With v3.1.0's debounce autosave that goes from occasional to constant, so
// "touch one cell, dirty the whole table" becomes the dominant diff source.
//
// Mutation-kill level, per the project's test bar: this path changes the
// BYTES written to the user's file, so each case pins exact output rather
// than a property. A mutation that pads by one space too many, or that
// truncates a grown cell, or that silently drops alignment, must fail here.
const assert = require('assert');
const { marked } = require('marked');
const { serializeTable } = require('../lib/editor/table-md.js');

marked.setOptions({ gfm: true, breaks: false });

// Same minimal element stub as test/table-md.test.js — table-md.js is
// constrained to childNodes/nodeType/nodeName/textContent/getAttribute.
function el(name, attrs, ...children) {
  return {
    nodeType: 1, nodeName: name.toUpperCase(),
    childNodes: children.map((c) => typeof c === 'string' ? { nodeType: 3, textContent: c } : c),
    getAttribute: (k) => (attrs || {})[k] !== undefined ? attrs[k] : null,
    get textContent() { return this.childNodes.map((c) => c.textContent).join(''); },
  };
}
function th(attrs, ...children) { return el('th', attrs, ...children); }
function td(attrs, ...children) { return el('td', attrs, ...children); }
function tr(...children) { return el('tr', {}, ...children); }
function table(headerRow, bodyRows) {
  return el('table', {}, el('colgroup', {}), el('thead', {}, headerRow), el('tbody', {}, ...bodyRows));
}

// 1. No original given → byte-identical to v3.0.0's minimal form.
{
  const t = table(tr(th({}, 'Col A'), th({}, 'Col B')),
    [tr(td({}, '1'), td({}, '2'))]);
  const { md, unsupported } = serializeTable(t);
  assert.deepStrictEqual(unsupported, []);
  assert.strictEqual(md, ['| Col A | Col B |', '|---|---|', '| 1 | 2 |'].join('\n'),
    'no original must still emit minimal form');
}

// 2. Hand-aligned original, NOTHING changed → byte-identical round trip.
{
  const original = [
    '| Name  | Age |',
    '|-------|-----|',
    '| Alice | 30  |',
  ].join('\n');
  const t = table(tr(th({}, 'Name'), th({}, 'Age')),
    [tr(td({}, 'Alice'), td({}, '30'))]);
  const { md } = serializeTable(t, original);
  assert.strictEqual(md, original,
    'an unchanged aligned table must round-trip byte-identical, got:\n' + md);
}

// 3. Hand-aligned original, ONE cell changed → only that cell's text moves.
{
  const original = [
    '| Name  | Age |',
    '|-------|-----|',
    '| Alice | 30  |',
  ].join('\n');
  const t = table(tr(th({}, 'Name'), th({}, 'Age')),
    [tr(td({}, 'Alice'), td({}, '31'))]);
  const { md } = serializeTable(t, original);
  assert.strictEqual(md, [
    '| Name  | Age |',
    '|-------|-----|',
    '| Alice | 31  |',
  ].join('\n'), 'changing one cell must leave every other byte alone, got:\n' + md);
}

// 4. Alignment colons are preserved AND keep the original width.
{
  const original = [
    '| Left    | Right   | Center  |',
    '|:--------|--------:|:-------:|',
    '| a       | b       | c       |',
  ].join('\n');
  const t = table(
    tr(th({ style: 'text-align:left' }, 'Left'),
       th({ style: 'text-align:right' }, 'Right'),
       th({ style: 'text-align:center' }, 'Center')),
    [tr(td({ style: 'text-align:left' }, 'a'),
        td({ style: 'text-align:right' }, 'b'),
        td({ style: 'text-align:center' }, 'c'))]);
  const { md } = serializeTable(t, original);
  assert.strictEqual(md, original,
    'aligned separators must keep both their colons and their width, got:\n' + md);
}

// 5. A cell that GREW past the original column widens that field — never
//    truncates. Padding is a minimum, not a maximum.
{
  const original = [
    '| Name  | Age |',
    '|-------|-----|',
    '| Alice | 30  |',
  ].join('\n');
  const t = table(tr(th({}, 'Name'), th({}, 'Age')),
    [tr(td({}, 'Bartholomew'), td({}, '30'))]);
  const { md } = serializeTable(t, original);
  assert.strictEqual(md, [
    '| Name        | Age |',
    '|-------------|-----|',
    '| Bartholomew | 30  |',
  ].join('\n'), 'a grown cell must widen its column, never be truncated, got:\n' + md);
}

// 6. A NEW column has no original width and falls back to minimal form.
{
  const original = [
    '| Name  | Age |',
    '|-------|-----|',
```

- [ ] **Step 3: 在 `table-md.js` 加入欄寬解析**

在 `lib/editor/table-md.js` 中 `function cellAlign(cell) {` 之前插入：

```js
  // ── v3.0.1 欄寬保留 ────────────────────────────────────────────────────
  // A cell FIELD is the text between two '|' delimiters, PADDING INCLUDED:
  // in '| a   | b |' the fields are ' a   ' and ' b '. A column's target
  // field width is the widest field that column has anywhere in the ORIGINAL
  // source — header row, separator row and every body row.
  //
  // That single number covers both styles for free. A hand-aligned table
  // reports its own alignment column; a minimal-form table reports 3, because
  // ' a ' and '---' are both 3 characters — i.e. exactly what this serializer
  // emitted before this feature existed. Which is why case 1 and case 2 of
  // test/table-width.test.js can both hold at once.
  //
  // A raw '|' never appears inside a cell in source THIS serializer produced
  // (it emits '&#124;'), but a hand-written table may use the '\|' escape, so
  // the split must not break on an escaped delimiter.
  function splitFields(line) {
    const t = line.trim();
    if (t.charAt(0) !== '|' || t.charAt(t.length - 1) !== '|' || t.length < 2) return null;
    const inner = t.slice(1, -1);
    const out = [];
    let cur = '';
    for (let i = 0; i < inner.length; i++) {
      const c = inner.charAt(i);
      if (c === '\\' && inner.charAt(i + 1) === '|') { cur += '\\|'; i += 1; continue; }
      if (c === '|') { out.push(cur); cur = ''; continue; }
      cur += c;
    }
    out.push(cur);
    return out;
  }

  // Target field widths per column, or null when `originalMd` is absent or is
  // not a table this can read. null means "no width source" and every caller
  // below then emits minimal form — the pre-v3.0.1 behaviour, unchanged.
  function columnWidthsOf(originalMd) {
    if (typeof originalMd !== 'string' || originalMd === '') return null;
    const rows = originalMd.split('\n').filter((l) => l.trim() !== '');
    if (rows.length < 2) return null;
    const first = splitFields(rows[0]);
    if (!first) return null;
    const widths = first.map((f) => f.length);
    for (let r = 1; r < rows.length; r++) {
      const fields = splitFields(rows[r]);
      // A ragged original is not a width source — bail rather than guess.
      if (!fields || fields.length !== widths.length) return null;
      for (let c = 0; c < fields.length; c++) {
        if (fields[c].length > widths[c]) widths[c] = fields[c].length;
      }
    }
    return widths;
  }

  // ' content ' right-padded out to `width`. NEVER truncates: a cell whose
  // content grew past the original column simply widens that column. Padding
  // is a MINIMUM, not a maximum — truncating here would delete the user's text.
  function padField(content, width) {
    const field = ' ' + content + ' ';
    return field.length >= width ? field : field + ' '.repeat(width - field.length);
  }
```
